# FamilyRecordSystem
Простая и удобная программа для совместного учёта расходов семьи. Помогает анализировать траты, планировать бюджет на месяц и копить на общие цели.


Возможности:


Учет транзакций: Быстрое добавление расходов с указанием суммы, даты, категории.


Категории: Поддержка встроенных и пользовательских категорий (например, Продукты, ЖКХ, Транспорт, Развлечения).

Использованные технологии:

Язык:C#

База данных: Microsoft Access

Диаграммы: draw.io
