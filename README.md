# FamilyRecordSystem

**FamilyRecordSystem** — простая и удобная программа на C# для совместного учёта расходов семьи. Она помогает отслеживать траты по категориям, анализировать расходы за выбранный период и планировать семейный бюджет.

## Возможности

- **Учёт расходов:** добавление транзакций с указанием суммы, даты и категории.
- **Категории расходов:** использование встроенных и пользовательских категорий, например «Продукты», «ЖКХ», «Транспорт» и «Развлечения».
- **Автоматический подсчёт потраченных средств:** пользователь вручную указывает дату начала и дату окончания периода, после чего программа автоматически рассчитывает общую сумму расходов за выбранный промежуток времени.
- **Анализ семейных трат:** просмотр расходов, чтобы лучше понимать, на что уходит бюджет.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone <https://github.com/bobikizz/FamilyRecordSystem.git>
   ```

2. Откройте проект C# в **Visual Studio** (файл решения `.sln`).
3. Убедитесь, что файл базы данных **Microsoft Access** доступен приложению. При необходимости настройте путь к нему в проекте и установите подходящий драйвер для работы с Access.
4. Соберите и запустите проект в Visual Studio (обычно клавишей **F5**).


## Как пользоваться

1. Добавьте расход, указав **сумму**, **дату** и **категорию**.
2. При необходимости создайте пользовательскую категорию.
3. Для подсчёта затрат укажите **дату начала** и **дату окончания** периода.
4. Просмотрите автоматически рассчитанную **общую сумму расходов** за выбранный период.
